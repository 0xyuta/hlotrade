# Notes for AI agents

Read `CLAUDE.md` first. It applies to every agent, not only Claude: what each contract, ops file and app rule does, the commands and the gotchas.

Then, on the owner's Mac, read `~/hlo-handoff/00-START-HERE.md`. That private folder has the live state, wallets, services, the runbook, the owner's rules and the open items. It is not in git. It holds no key values.

Rules that catch new agents out:

- HLO is live on mainnet. The contracts are immutable, and published checkpoints are never revised.
- Never print, log, commit or upload a key or token. They are in env files outside this repo.
- The only author here is `yuta`. Do not add `Co-Authored-By` or any tool's trailer, and never write the Mac's user name in this repo.
- The vault pops. Never say "jackpot", "lottery", "prize", "motherlode" or "win", and never name another project as HLO's model.
- Stage files by name. Push, merge or make the repo public only when the owner asks.
